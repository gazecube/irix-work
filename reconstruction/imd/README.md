# Clogin Imd compatibility subset

This directory is a standalone snapshot of the independently reconstructed Imd panel surface required by the Clogin Pandora path.

The code is derived from shipped binary/symbol evidence for `libimdIconPanel.so` and related runtime artifacts. It is not leaked IRIX source.

Only the subset currently needed by Clogin is kept here. The canonical broader reconstruction remains in IID's `libimdIconPanel` tree; additions should be copied only when Clogin proves the dependency is needed.
